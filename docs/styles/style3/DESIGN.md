# style3 · 赛博朋克牌桌

2026-11-19，首轮主桌设计约束。以 DX main 的 9fcd8a5ab1d6e9da807d2d2cf9218f8741e71990 为开发起点。功能参照 style1，容量参照 style2 的最终运行记录。已核对 MX reorg-qa 远端 4a0a9da931e567013ec1f1de97631002f949c747，与 DX 上轮集成记录一致，增量为零。H5 基线树为 362b0108c86e11f202b721dedab041fbb1bf2557。

## 首轮主桌出稿要求

以深夜城市里的地下牌室为方向。桌边采用分段枪灰金属护轨和局部品红反光，桌内是低反差墨蓝织物。电青灯带只点亮当前行动者一侧，用亮度变化和有缺口的计时环同时表示回合。城市灯箱仅作为边缘远景，中央牌面、下注和金额下方留素色。

| 元素 | 材质、颜色与状态 |
| --- | --- |
| 牌与底池 | 亮象牙白牌面，红黑花色保留原符号，暗牌遮罩服从牌角。金额用等宽数字和实色底，保留 BB 与长金额。 |
| 玩家 | 切角身份牌配圆形头像。昵称与余额分行；弃牌降低头像饱和度，当前玩家用青色计时边，赢家用琥珀色及现有标识。 |
| 行动 | 弃牌用石墨色，过牌或跟注用青边，加注用实色电青。全下另用警示图标和文字。交互标签保持原语言，正文不用发光描边。 |
| 桌内面板 | 烟蓝玻璃、细金属边；蒙版只在打开时出现。标题与操作栏固定，列表内部滚动。选中态同时用色块与勾选表示。 |
| 动效 | 发牌和结算沿用现有触发点。霓虹不循环闪烁；减少动态效果时仍可由静态边框识别行动座位。 |

## R2 · 酸雨街机

用户反馈首轮赛博朋克感不足。当前美术方向以[语音桌美术稿](design/round2/voice-art.png)与[桌轨材质图](design/round2/material.png)为准，用户已确认。左侧青色灯管裸露在夹具里，右侧磨损的品红护甲承接城市反光，桌角用酸黄斜纹护片。紫色桌布承载象牙白牌和底池，头像铭牌、跟注与加注采用同一套机台金属造型。头像为虚构美术示例，运行时保留玩家头像来源。

- Stitch 二稿：[提示词](design/round2/request.txt)、[原始导出](design/round2/stitch-style3-nightport-round2.zip)。三张界面及规范已归档；导出含桌外演示导航，侧座与牌行仍有交叠。
- 内置 ImageGen：先生成材质原图，再结合 Stitch 语音桌结构生成完整美术示意。[材质提示词](design/round2/material-prompt.txt)及[整桌提示词](design/round2/voice-art-prompt.txt)已保留。两张图均未用作生产 UI。
- 完整美术稿可见 8 座、5 张公共牌、五档快捷、三行动键和四项语音桌导航。但有两个计时环，缺少侧注、独立聊天入口及认证位置。实现前按现有状态与真实组件核对，快捷读值沿用业务；320px 点击热区和长金额避让仍需运行时验证。本轮仅供美术方向评审。

## 夜港运行版本（style3）

已按用户确认的 R2 语音桌与机械桌轨实现。Style3 作为 DX 默认皮肤，仍可按实例选择 style1/2。桌面筹码使用带 18 道压齿与闪电搪瓷印记的瓶盖，五档快捷键分别有不同瓶盖颜色；下注、底池、加注、普通筹码钱包和牌谱沿用同一视觉，钻石保持独立。专属头像仅在玩家未提供或加载不到头像时使用。默认牌背采用电路印花，自选的六种颜色也已重绘。

### 变更范围

- 两套皮肤采用相同的座位和触控空间约束。原 style2 的几何规则移至 src/assets/compact-table，颜色、图片和装饰分开维护。PicnicLayout 的原导出保留。
- SpriteAtlas.paint 在绘制已知筹码资源时更新语义类名；CardView.paint 标明当前牌背。组件自身区分筹码和钻石、默认和自选牌背，避免根据 atlas 坐标猜测图片含义。style1/2 对这些标记没有新增绘制规则。
- 公共装配只在 UiConfig 选择默认皮肤，两个入口转导出 style3。离线工作台和验收脚本支持选择候选皮肤与独立报告目录。牌局计算、网络、H5 源码没有变化。

### 验证

应用、离线工作台类型检查、完整生产构建及 288 项测试通过。114 个场景的[双风格结构对照](implementation/parity.json)、[六项行为对照](implementation/behavior.json)、[20 组容量](implementation/capacity-results.json)、[15 组底栏与间距](implementation/footer-results.json)、[17 项交互及热区](implementation/interaction-results.json)通过。[生产检查](implementation/production.json)验证默认九座均衡布局、宿主导出与素材解码。本轮未做实服和实体机验收。

复验时设置 MX_TEST_SKIN=style3、MX_OUTPUT_DIR 为本轮输出目录，并按本机环境指定 MX_PLAYWRIGHT_MODULE。使用 tests/fixtures 下的 verify-style-parity、verify-style-behavior、verify-style2-capacity、verify-style2-footer、verify-style2-interactions 和 verify-style2-production 脚本，各脚本沿用现有命名。

### R2 素材复验 · 真实大厅与跨端口挂载

真实 H5 页面曾把样式中的桌面图片解析到大厅端口。该路径返回 HTTP 200 和 HTML，浏览器无法解码图片。DX 的 dev:h5 现按游戏资源服务的监听地址生成绝对素材 URL。保留 Vite 生产构建的相对资源路径。

行动键、快捷键底板、底栏按钮、玩家与底池铭牌取自 R2 图中的机械面板。运行时填入本地化标签、状态和金额。实服头像优先显示玩家上传的图片。原稿展示语音桌，八人测试场景展示普通桌，其导航数量、下注、房间信息及认证标识按桌型和数据展示。

[原稿与同尺寸运行截图](implementation/r2-table-comparison.png) · [八个弹窗截图](implementation/r2-panels.png)。截图使用测试牌局，菜单、个性设置、战绩、牌谱、聊天、表情、保险说明、买入安全提示均由真实组件打开。

浏览器回归入口为 tests/fixtures/verify-h5-skin-assets.cjs。启动 dev:h5 后运行脚本，使用 MX_PLAYWRIGHT_MODULE 指向本机浏览器测试依赖，MX_OUTPUT_DIR 可指定截图目录。脚本先在真实大厅检查预加载，再在同一对来源下通过 AuditHost 检查牌桌。在本轮主桌与八个面板中，83 种本地图片成功解码。另通过生产构建、生产预览与 17 项浏览器交互检查。实服登录和牌局数据独立于这组截图。

### 实服旁观复验

从真实 H5 大厅进入九人德州桌旁观。现场读到六张已解码的玩家头像，底池、下注瓶盖与电路牌背正常显示。实桌打开了菜单、个性设置、战绩、牌谱、规则与聊天。牌谱从加载态更新到历史手数。旁观点击表情时，房间提示“观众无法发送表情”。本人行动键和五档快捷继续以测试牌局验收。

俱乐部房间同时显示安全卫士与客服，之前两者的热区重叠。修正后，655 像素宽竖屏上两个按钮各为 44×44 像素，间距 8 像素，实测分别打开安全卫士和客服会话。修正 H5 页面焦点滚动造成的桌面整体上移，使游戏宿主顶边回到视口顶部。跨端口验收已增加有俱乐部权限的旁观场景，覆盖两个独立入口和 84 种已解码本地图片。

当前逐项覆盖、保留原因和设备截图见[手机验收与替换清单](手机验收与替换清单.md)。
