## 仍沿用的内容

| 内容 | 理由 |
| --- | --- |
| Gaming Labs／BMM 认证标志 | 第三方认证标识保留原始图形和文字。 |
| 真人头像、俱乐部标志、视频流、服务端表情分类图、业务二维码 | 内容由用户或服务端提供，具有身份、目录或交易含义。皮肤替换外框和缺省图。验收数据还会把一张旧头像作为用户上传图的样例传入。 |
| 17 个表情的角色动画、WIN／ALL IN、赠礼飞行动画，以及 9–14 号桌的动态叠层 | 继续使用项目既有 Spine 骨骼、贴图和播放时序。编号桌底图、礼物选择图标和表情控件已换。原角色、动作和特效画面本身仍是旧美术。 |
| 真实大厅、登录面板、浮动 LOG、系统键盘和浏览器栏 | 分别属于 H5 宿主和设备。此分支修改 DX 牌桌内的组件。 |
| 文字、牌值、真实金额与本地化文案 | 继续从游戏和语言包读取，保证翻译、金额显示与下注行为一致。 |
