## 设计约束 v1

本节供 Stitch 出稿和后续验收直接使用。硬约束来自冻结代码及当前用户要求；颜色、造型和新的具体坐标留给设计。原版坐标仅作为参考，不要求卡通新稿逐像素复刻原版。

### 视觉方向

全卡通可爱、柔软圆润、有轻微玩具质感。候选方向为奶油白、薄荷绿、杏桃色与少量葡萄紫；这是设计提案，最终以用户审定稿为准。装饰放在牌桌空白区域，不遮盖点数、花色、昵称、金额、倒计时和可操作控件。头像来自用户动态内容，不把全部玩家写死为卡通角色；卡通头像框和占位头像可设计。

视觉层级：当前行动和剩余时间 → 本人手牌与可用操作 → 公共牌与底池 → 对手信息 → 装饰。弃牌、跟注/让牌、加注要区分；禁用、选中、等待、错误不能只靠颜色表达。昵称可省略，金额不能截掉关键数值。保留正式多语言 key；截图里的数字仅是示例。
