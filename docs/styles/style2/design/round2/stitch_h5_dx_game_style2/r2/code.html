排道渲染规则与视觉策略

⚡ 行动状态机与自动预选规则契约
场景状态行为与交互说明
可让牌时 跟注按钮自动转为“让牌(Check)”；若点击弃牌，弹出防误触次级确认弹窗。
不可让牌时 跟注按钮显示精确差额“跟注 X BB”；加注按钮根据 minRaise 计算最小加注。
自动预选失效 当其他玩家下注额变化、跨街/跨手牌、重连同步、或玩家留座托管时，所有预选立即重置清空。
弹窗与遮罩 弹窗统一带遮罩(半透明模糊)；点击空白区域关闭或二次拦截确认；弹窗关闭不得误穿透手牌点击。
📱 极小屏与短屏响应式规则 (375×500 / 320×400 实测方案)
视口规格 布局避让方案 不可妥协契约 (严禁破坏功能)
375×500 (短屏) 毛毡高度缩窄至396px，8人座位向心收拢15%，手牌与五档快捷间距微调为4px；加时与聊天贴紧左右侧壁。 五档快捷全部保留，绝不擅自压缩为三档；加时与聊天热区独立，严禁合并；8人座位全部在屏。
320×400 (极小屏) 启用 Nano 高密度排版模式：文字与牌面缩放至 75%-80%，底栏高度压至 32px，快捷按钮缩为微型曲奇胶囊。 仍保留全部8人与五档快捷；字号确保在点阵渲染下数字与花色清晰可辨；所有固定入口完整存在。
