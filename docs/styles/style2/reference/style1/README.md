# style1 参考截图基线

本目录永久保存本次 style2 的 style1 参考图，后续 style3 优先引用，不重新批量截图。已收到 balanced-table.png 用户原图，并使用用户授权的 Playwright 补拍15张固定尺寸参考图。共16张；[图册](index.html)与 manifest.json 记录尺寸、场景、来源、时间和哈希。工具截图期间页面错误为0。

图片收到后按 manifest 中的文件名保存，核对场景和尺寸，填写实际采集时间、裁剪区域、来源（用户截图或工具采集）及 SHA256。440×782 是牌桌区域尺寸，不能把包含浏览器工具栏的整图冒充这一尺寸。无法确认的信息保留未知，不猜测。

新截图先保留原始文件，需要裁剪时另存派生文件，并记录原图关系。区分基线 style1、Stitch 设计稿与未来 style2 实现截图，不相互覆盖。设计稿保存在 ../../design/，实现截图未来放在 ../style2/。

此目录不使用被忽略的 docs/qa 或临时 /tmp。用户要求跨风格复用，因此资料随项目保留；提交时按仓库 LFS 规则处理图片。不要归档账号、token 或真实敏感个人信息。
